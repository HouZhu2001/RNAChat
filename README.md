# RNAChat: RNA Function Prediction with Large Language Models

RNAChat is an advanced AI system that combines large language models with RNA-specific encoders to predict RNA functions and generate comprehensive descriptions of RNA molecules. This project represents a significant advancement in computational biology, enabling researchers to understand RNA function through natural language processing.

## 🧬 Overview

RNA molecules play crucial roles in cellular processes, from protein synthesis to gene regulation. Understanding their functions is essential for drug discovery, disease research, and synthetic biology. RNAChat leverages the power of large language models (specifically Vicuna-13B) combined with specialized RNA encoders (RiNALMo) to:

- **Predict RNA functions** based on sequence and structure
- **Generate detailed descriptions** of RNA molecules in natural language
- **Classify RNA types** and their biological roles
- **Provide insights** into RNA-protein interactions and pathways

## ✨ Key Features

- **Multimodal Understanding**: Combines RNA sequence, structure, and functional annotations
- **Natural Language Generation**: Produces human-readable descriptions of RNA functions
- **High Accuracy**: Outperforms baseline models in RNA function prediction tasks
- **Scalable Architecture**: Built on state-of-the-art transformer models
- **Comprehensive Evaluation**: Includes BLEU scores and semantic similarity metrics

## 🏗️ Architecture

RNAChat uses a sophisticated architecture that integrates:

1. **Vicuna-13B**: Large language model for natural language understanding and generation
2. **RiNALMo**: RNA-specific encoder for sequence and structure representation
3. **Custom Training Pipeline**: Specialized training for RNA function prediction
4. **Evaluation Framework**: Comprehensive metrics for model performance
